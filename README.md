# Cassino do Japa

Portal estático e responsivo para uma noite temática de cassino. Inclui regras de jogos, dinâmica das fichas, cardápio, ranking local e QR Codes para impressão.

## Rodar localmente

Abra `index.html` no navegador ou sirva a pasta com qualquer servidor HTTP estático.

## Publicação

O site é compatível com GitHub Pages e não exige processo de build.
